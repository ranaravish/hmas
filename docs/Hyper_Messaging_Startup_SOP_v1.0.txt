Hyper Messaging Platform - Startup SOP v1.0

HMAS (Hyper Messaging Automation System) is a modular, configuration-driven communication platform designed to automate, secure, and orchestrate messaging workflows across multiple applications, services, and communication channels.






========================================================== PROJECT
FOLDER ==========================================================

D: │ ├── AMAS_Server ├── School_WhatsApp_Server ├── gateway └── Old code

========================================================== STARTUP
PROCEDURE ==========================================================

STEP 1 : Open Command Prompt


STEP 2 : Start AMAS Server

Open CMD-1

node D:\Projects\hmas\servers\school\school_3002


Expected: - WhatsApp Connected - AMAS Server Listening on Port 3001

STEP 3 : Start School WhatsApp Server

Open CMD-2

cd D:_WhatsApp_Server node server.js

Expected: - WhatsApp Connected - School Server Listening on Port 3002

STEP 4 : Start Gateway

Open CMD-3

node D:\Projects\hmas\gateway\gateway.js

Expected: - Gateway Listening on Port 3000

STEP 5 : Start ngrok

Open CMD-4

ngrok http 3000

Expected: Forwarding https://xxxxxxxx.ngrok-free.app

Copy this URL and use it in Google Apps Script / PHP if required.

Open CMD-5

cloudflared tunnel run hmas-test 

in PowerShell
